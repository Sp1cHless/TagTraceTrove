# T³ — Tag · Trace · Trove

> 一个**本地优先**的个人索引：把你在网上发现的作品、媒体、作者、链接，收进一份**属于你自己**的数据里，
> 随时可读、可改，不依赖来源网站是否还在。

**T³** 把散落的收藏夹和截图变成一座真正的资料库：日常浏览快、标签优先导航、数据库握在自己手里。
不上传任何数据，没有账号、没有云端、没有锁定。

## ✨ 主要功能

| | |
| --- | --- |
| 🖼️ **以画廊为主** | 每一类作品就是一座画廊，封面用有纵深的叠层卡片呈现——没有表格，没有文字行。 |
| 🏷️ **标签优先，但有结构** | 标签落在 **板块 → 维度** 里，同一个标签处处含义一致；作品标签与作者标签各自独立。 |
| 🔎 **真正的搜索与筛选** | 跨作品／标签／作者全局搜索，外加每座画廊的维度筛选——每加一个标签，结果只会更窄。 |
| 👤 **认真的作者系统** | 作者页、名下作品、文件夹（纯展示的分组，不动作品本身）、跨站点同一人的别名组、一键「全部转为多作者」。 |
| ⭐ **两个方向的评分** | 作品自己的维度，加上作者本人的评分，以及作者名下作品的概括评分——不会让一部电影和它的演员共用一个毫无意义的分数。 |
| 📁 **合集** | 给作品或作者用的轻量文件夹，一层子文件夹，可单独开关 NSFW。 |
| 🕘 **不碍事的使用记录** | 浏览、点赞、最近观看**只用于排序**，永远不会变成一个要你操心的筛选条件。 |
| 🌐 **从网页导入** | 指向一份站点导出，它会变成一个事务里的作品、作者、标签和来源链接，并带复核步骤。 |
| 🕷️ **内置站点爬虫** | **SiteProbe** 在浏览器里学习某个网站的结构，之后自己保持更新。任意网址都能变成一条作品。 |
| 📵 **手机可离线** | Android 端共用同一份库：断网也能浏览、编辑、创建、补图、合并，联网后自动同步。 |
| 🌗 **明暗主题、六套配色** | 六套色彩预设，纯手写 CSS，没有 UI 框架。 |
| 🈶 **中英双语** | 完整 English / 简体中文 界面，起始语言跟随设备。 |
| 🔒 **本地所有权** | SQLite 在你机器上，素材在一个你能直接拷贝的文件夹里，备份与恢复内置。 |

## 🧱 设计取向

多数工具要求你按**它们**的方式整理。T³ 几乎不要求你先做出配置，然后就让开路：

- **日常使用优先。** 点一下胜过配半天；常用操作从不弹对话框。
- **先能快速打标签，再谈完美元数据。** 你愿意打的粗标签，胜过你永远不会去建的字段。
- **来源可选，永远不等于身份。** 一条作品是**你的记录**，不是一个网址；站点消失，记录仍在。
- **本地所有权。** 你的库就是一个文件加一个文件夹，拷贝即备份。
- **复杂度必须被真实使用挣来。** 功能在真实需求出现时才到来。

## 🚀 快速开始

### 环境要求

- 托盘启动器需要 **Windows 10/11**（服务端本身是可移植的）
- **Node.js 22 LTS** 与 **pnpm 10**（仅首次构建／源码运行需要）
- 现代浏览器（Chrome/Edge/Firefox）；手机端另需一台 Android 设备。

### 源码运行

```bash
pnpm install
pnpm build              # 构建服务端 + 前端
pnpm start:server       # 在 http://127.0.0.1:8765 打开应用
```

打开 `http://127.0.0.1:8765`。带热更新的开发模式：

```bash
pnpm dev:server                    # API 在 :8765
pnpm --filter @t3/web dev          # 前端在 :5173
```

### 打包运行（无需终端）

在仓库根目录双击 **`T3.exe`**：托盘启动器会在后台启动服务、打开浏览器，并常驻系统托盘直到你退出。
首次运行会自动构建前端。`T3.bat` 做同样的事，只是跑在一个控制台窗口里（关掉窗口即停止）。

之后打开托盘里的 **「允许手机连接（LAN）」**，手机就能在同一网络下访问。

### 你的数据

默认全部位于 `apps/server/.data/`：

```text
.data/library.db      SQLite 资料库
.data/assets/         封面、预览图、缩略图
.data/backups/        整库备份
.data/templates/      各画廊的模板文件
```

`pnpm db:backup` / `pnpm db:restore <目录>`（或应用内的系统页）会把库与素材一起快照、一起恢复。
它就是一叠文件——把文件夹拷走就完成了备份。

## 📱 手机端

Android 端是套在 WebView 外壳里的同一套界面，通过局域网与桌面端配对，连接经过加密并做证书固定。
它自带完整的**离线资料库**：断网也能浏览、编辑现有作品、带图创建新作品、加标签和作者——联网后立刻自动重放全部操作。

从源码构建（需 Android SDK + JDK 21）；构建／打包链路与真机验收历史见 `docs/mobile.md`。

## 🕷️ 从网站导入

两条入口，都在 T³ 界面内：

1. **SiteProbe** —— 内置工具，打开真实浏览器，让你点选页面上在意的部分，并为该站点学出一套规则。
   可以喂给它一个作品网址、一个作者页，或一个收藏夹列表。
2. **导入提交** —— 经复核的事务式提交，把一次抓取的结果变成作品、作者、内容与来源链接，
   带按作者的评分步骤，且绝不猜测未映射的字段。

导入是幂等的：对同一站点重跑会跳过你已经有的内容（并且替你记住每个站点的工作 id 与更新游标）。

## 🧰 常用命令

```bash
pnpm test              # 单元 / 组件测试
pnpm test:integration  # 真实 SQL 集成测试
pnpm typecheck         # 全部包的 TypeScript 检查
pnpm lint              # ESLint
pnpm db:probe          # 校验 schema 与核心场景
pnpm db:doctor         # 只读完整性检查
pnpm db:backup         # 快照资料库与素材
pnpm import:cursor ... # 抓取游标 status/filter/list/set
pnpm merge:authors     # 合并重复的作者拼写
```

## 🗂️ 仓库结构

```text
apps/server/     本地 API、SQLite、各 repository、导入、同步
apps/web/        Vue 3 前端（无 UI 框架，手写 CSS）
packages/shared/ 两端共用的 Zod 契约
siteprobe/       内置的 Python 抓取／规则构建工具
tools/           托盘启动器（C#）与字体子集化脚本
spikes/          Android WebView 外壳与真机探针
docs/            架构、接口、数据库、离线、手机、UI、SiteProbe
```
