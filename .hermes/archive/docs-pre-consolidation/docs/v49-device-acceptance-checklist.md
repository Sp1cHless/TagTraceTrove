## B. 本批新功能（都在离线状态下做）

## 提醒

- 全程不卸载、不清数据；升级失败先看诊断 build 号。
- B5 合并的两部作品必须同类型、同一位作者名下。
- B6/B7/B9/B10 可以在同一次断网期间连续执行，存为模板后也可以继续加维度、移动／增删改标签；中途不需要联网。完成整条操作链后再统一重连核对最终布局和待同步队列。
- 本批功能全部是自动化测试通过后的首次真机验证——任何与预期不符的现象都有价值。
- 离线新建的作品还没同步前，也可以补图片、删图片、排序和删除作品。重点检查「加封面 → 删除」「连续换两张封面」「新建 → 修改 → 删除」整个过程保持断网，界面即时生效；最终统一重连，核对数据与待同步状态。
- 合并**已经排队但还没同步**时：被吸收作品的图片会**留到同步那一刻**才清掉（所以现在取消还不算太晚——只是取消排队的合并目前没有界面，先别同步即可）。
