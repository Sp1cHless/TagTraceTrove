# T3

> A personal database for collecting, organizing, editing, and revisiting content from across the web — your permanent Internet memory.

**T3 is currently under development.**

T3 is a personal database tool designed for keeping track of things you discover online — works, media, creators, links, and other content that would otherwise remain scattered across different websites.

The idea is to keep the data **locally organized, freely editable, and independent of the original platform**, so your records remain useful even when websites change or disappear.

### Features

- Flexible metadata and tagging
- Custom collections and organization
- Search, filtering, and sorting
- Personal status, ratings, and notes
- Links back to original sources
- Importing metadata from webpages
- Customizable interface for different types of content

The project is primarily built for personal use, with an emphasis on **flexibility rather than enforcing a fixed database structure**.

More features and documentation will be added as development continues.
