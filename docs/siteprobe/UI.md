再下面是how to work the adapator的注释，跟作品适配器的不一样：
1，列表适配器会打开该列表并展示在该列表下找到的所有作品，请选择一个作为参考（选择那个你能真实打开的，一般第一个即可）
2，有的网站是否登录会影响展示的数量，例如登录状态下你看到30个搜索结果，不登录只有20个。这种情况下依旧需要特殊适配器。
3，进入的作品页面是在列表下能看到的该作品的信息，所以会比之前作品适配器时看到的少。不要担心，实际录入时依旧是根据之前适配的全信息录入。
4，选对信息非常关键，这一步的目的是从整个列表的复杂信息中正确找到一个个作品并定位基本信息（封面、标题等）
