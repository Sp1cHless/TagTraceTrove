1. 第一次运行

启动

  • 在仓库根目录双击 T3.exe：桌面服务在后台启动，自动打开浏览器，并常驻系统托盘。右键托盘图标可退出。
  • T3.bat 做同样的事，只是跑在一个控制台窗口里——关掉那个窗口即停止服务。
  • 首次启动会自动构建前端，稍等片刻。之后再次双击若服务已在运行，只会重新打开浏览器。

数据放在哪

默认都在 apps/server/.data/：

路径内容
library.db整个资料库（SQLite 单文件）
assets/封面、预览图、缩略图
backups/整库备份
templates/各画廊的模板文件
它就是一叠文件把这个 .data 文件夹整体拷走就是完整备份。

为手机开放访问（可选）

右键托盘图标 → 打开 Allow phone access (LAN)。这会用 0.0.0.0 重启服务并列出本机的局域网地址；点选一项即可复制，粘贴到手机。关闭它则恢复只监听本机。

2. 界面总览

左侧栏（导航）

侧栏是最高优先级的导航：在任何页面、任何层级，点侧栏立即切换过去。自上而下通常有：

  • 首页 Home、搜索框、若干画廊（每个 Entry 类型一座）、作者 Authors、合集 Collections、稍后再看 View later、最近观看 Recently viewed、随机推荐 Random pick。
  • 手机端（窄屏）侧栏变成一个可滑出的抽屉，支持遮罩、Esc 与浏览器返回键关闭。

顶栏

  • 左侧是返回按钮（在首页时禁用）与当前页标题。
  • 右侧依次是：主题切换（明/暗）、设置齿轮。

右下角浮动按钮

每个页面右下角固定有两个按钮：上为返回上一级，下为回到顶部。它们与顶栏的返回是同一个动作，所以长页面里也随时能返回。

返回会记住你来时的位置从作者页打开作品、再返回，会回到那个作者的同一页、同一滚动位置、同样的筛选与排序。打开新页面总是从顶部开始。

3. 首页 Home

首页是「继续看下去」的入口，不是统计面板。

  • 主区（Hero）：一句问候 + 「新增条目」按钮，直接进入新建作品。
  • 氛围小结：会轮换显示「如今收录 N 条」「你有 M 座画廊」「最近看过《…》」，是氛围提示，不是精确统计卡。
  • 最近观看：最近打开过来源链接的作品，点一张卡片直接进入其详情。
  • 最近的画廊：给几扇门，回到常用的画廊。
  • 空状态：库里还没有内容时，显示「添加第一条记录」。
  • 如果所有画廊都被 NSFW 设置隐藏，首页会直接提示并提供「显示 NSFW 内容」按钮。

4. 画廊 Gallery

浏览

每座画廊对应一个 Entry 类型（如 comic、game）。用全新类型创建一条作品，那座画廊就自动出现。作品以封面叠层卡片呈现，一页多行，行数可在设置里调。

排序

画廊标题旁的 Sort 下拉提供：最新优先、最早优先、标题 A–Z、标题 Z–A、按类型，以及各类评分/使用排序（见下）。

筛选栏

网格上方是筛选栏，由若干行组成，所有条件用 AND 叠加——每多选一个标签，结果只会更窄：

  • 维度 + 标签行：输入即联想（TagCombobox，近似拼写也认）。同一个标签只能在整个筛选栏里选一次。
  • 所有标签行：不限定维度地匹配标签。
  • + Authors：新增一行作者筛选，行内作者之间是 OR。
  • 筛选进行中，标题会显示 命中 / 总数；同时作者页的文件夹会被临时展开，所有命中作品平铺成一个网格，清空筛选即恢复。

评分与使用排序

每个评分维度在排序下拉里多出一条 「应用作者评分」（带 👤 标记）：作品自己没有该维度评分时，借用其作者在同一维度上的评分（取作者中的最高分；作品作者数 ≥ 4 时不借用）。评分筛选只看作品自身评分。

使用记录（观看数 / 最近观看 / 点赞数）只出现在排序里，不提供数值或日期筛选条件。

移动画廊顺序

侧栏里用 Move Galleries 进入排序模式，用上/下按钮调整。也可在设置里调整每页行数。

分页

网格底部的分页条按每屏实际能放的卡片数翻页；手机端每页行数翻倍。切换筛选或排序会回到第 1 页。

横向卡片与无图封面

画廊标题旁的卡片布局按钮可以切换竖向网格与横向卡片。横向卡片左侧显示封面、右侧显示标题，每行最多两张，窄屏一张；每页使用设置行数的两倍。布局按画廊保存，切换需要连接电脑端，离线副本不保存这个设置。

在线列表里，没有封面或预览图的作品会优先显示第一条可读内容，其次是标签，最后才是标题首字母。来源网址会跳过；长文字按封面空间截断。已保存的离线副本使用原有占位样式。

5. 作品详情 Entry

只读视图

  • 顶部是标题、类型徽标、日期、页数/时长等统计行，以及工具栏。
  • 工具栏上有 Edit、Like（👍，可重复点）、稍后再看时钟按钮、📁+ 加入合集、删除等。
  • 板块（Section）与维度（Facet）按布局排列，标签以 chip 呈现；双击标签打开跨画廊的标签结果页。
  • 评分区：只读时已评分显示部分填充的 ★，未评分显示「未评分」。
  • 内容区：有序的内容行（如 Source URL、description、短评等）。content_type 是自由文本。
  • 打开作品的来源链接（点 Source URL）才会记一次浏览——打开详情卡片本身不算。

编辑视图（点 Edit）

  • 标题：双击标题进入就地编辑，Enter 或失焦保存，Esc 取消。
  • 类型：切换类型等于换画廊。
  • 日期 / 页数 / 时长：就地编辑。日期接受 yyyy-mm-dd、yyyy-mm 或 yyyy；时长接受 h:mm:ss / mm:ss / ss。时长可清空。
  • 板块与维度：空板块首行同时给出 + 维度 与 + 标签；已命名维度有左标签列与右标签列；可对维度上/下排序。板块标题在编辑态可重命名或删除。
  • 标签：拖动可换维度，双击可重命名（只改这一条作品的该标签），也可删除。
  • 内容：新增、编辑、删除、上下移动，回车或失焦保存。
  • 评分：每行一个半星选择器（0.5–5 半星步进）加清除按钮；+ Rating 为整座画廊新建一个共享评分维度。评分行的上/下按钮重排的是整个画廊共享的维度顺序。
  • 作者：可用简洁控件新建 / 关联 / 解绑作者；匹配永远由你确认，绝不自动。
  • 全部转为多作者：当作品有 ≥2 位作者且不全是 multiple author 时出现。它把所有署名作者替换为一个共享的 multiple author 作者，不判断谁「值得留下」。只出现在这部作品里的作者会归零并从列表消失（行不删除，后续导入仍可重新关联）；有其它作品的作者只是少这一部。
  • 保存为模板 / 应用 tag 布局（工具栏）：前者重建该类型的共享布局；后者只把本作品的「标签→维度」位置同步给同类型的其它作品（跳过本作品没有的标签）。
首次结构化的提醒当你在某座画廊的唯一一件作品上点 Done，而该画廊还没有任何板块时，会弹出询问：是否把这件作品的板块与维度应用到整座画廊。选择应用，效果与工具栏的「保存为模板」相同。

合并作品

在作者页的编辑态进入 Merge works / 合并作品：点选两件同画廊的作品，选择保留哪一件、用哪个标题、是否合并标签、是否把被吸收作品的来源链接复制过去。服务端在一个事务里完成复制并删除被吸收的作品；被吸收作品的其它内容、媒体、评分、使用、文件夹、合集、稍后再看都不会被复制。

6. 新建作品

从首页「新增条目」或侧栏进入新建页。

  • 填标题（必填）与类型：类型可以填新名字（新画廊）或已有名字（加入该画廊）。
  • 封面 / 预览：选择本地图片上传；新上传会自动生成 512px 的卡片缩略图，原图用于详情页。
  • 来源 URL：可填网址，也可填本地文件的完整路径。
  • 模板按钮（画廊字段下方）：已有画廊显示「模板就绪——打开详细编辑」，新类型显示「新画廊——创建它的模板」。它总是先用已填信息创建作品，再打开这件作品自己的编辑器。
  • 展开「初始内容 / 初始评分 / 稍后再看」可在创建时一并写入。
离线也能创建手机/离线状态下同样可以新建作品（含封面）——它会进入待同步队列，联网后自动落地。详见第 13 节。

7. 作者 Authors

列表

  • 列表只显示名下至少有一件作品的作者。删掉某作者的最后一件作品，只会让他从可检索处消失，行不会删除，后续导入可重新关联。
  • 可按主导画廊类型筛选，并按 最近观看 / 观看最多 / 点赞最多 排序。
  • 两组独立筛选：Author tags（作者自己的标签词表）与 Works contain tags（名下作品携带的标签，不会复制到作者身上）。多个作品标签必须同时出现在同一件作品上。
  • 卡片上以淡色显示该作者的其它已记录拼写（别名）。

详情

  • 信息板：基本信息、作者标签（独立词表）、作者内容（一条短评/备注）。作者没有板块/维度布局。
  • 评分区：半星选择、+ Rating、共享上/下重排。评分属于该作者的主导画廊分区；没有作品的作者会显示提示。
  • 作品区：以画廊风格卡片分页展示名下作品；打开作品复用作品的详情导航，返回时回到该作者。
  • 文件夹 Directories：纯展示的分组，不改变作品类型、也不产生新画廊。`+ Directory` 新建；把一张散作品拖到另一张上会新建文件夹，拖到已有文件夹上会移入；文件夹右上角可编辑标题与简介（就地保存）；还可把作品「移出」回散作品。
  • 作者别名（在进阶功能的「作者别名」标签页维护）：一个显示名 + 一组解析到它的拼写（如假名/汉字/中文译名/罗马字）。保存后会立即合并已存在的重复作者行，使任何拼写都指向同一个人。

8. 合集 Collections

  • 作品合集与作者合集两类，类型在创建时固定。作品合集可以有一层子文件夹；作者合集是扁平的。
  • 合集页是一排平铺的分页：先是每座画廊，然后（如有）「未分配」，最后是「作者」。NSFW 画廊在 SFW 模式下会连同它的分页一起隐藏。
  • 编辑态：新建、删除、拖动重排文件夹。进入某个作品合集后，有 + New subfolder；子文件夹以文件夹卡片显示在成员之上，点进去不退出编辑模式。
  • 普通模式点成员打开作品详情；编辑模式点成员是「选中待整理」，然后用子文件夹上的 Move here 或子文件夹内的 Move out 移动。成员卡片右上角的删除控件只解除「与当前文件夹的关联」，不删除作品。
  • 加入合集：作品详情页与作者信息板有常驻的 📁+ 按钮；菜单里已加入的显示 ✓ 且禁用。菜单优先列出投向该作品所在画廊的文件夹，外加「未分配」的文件夹。
  • 为全部添加 tag：在文件夹编辑视图里可给文件夹内所有作品（含子文件夹）加同一个标签；每个作品沿用其画廊既有的维度归属；没有结构的画廊会被跳过并计数。

9. 稍后再看 / 最近观看 / 随机推荐

稍后再看 View later

  • 独立的作品与作者两个列表，保存在资料库里，所有连到本库的桌面/手机浏览器共享。
  • 在作品页/作者页点时钟按钮加入或移除；加入后变成「已勾选的时钟」。
  • 列表按加入顺序排列，各客户端会自行拉取同步（不要求同时在线）。

最近观看 Recently viewed

  • 按画廊分组、浏览器风格标签页。默认「最近观看」模式，隐藏从未看过的作品，最多显示 72 张卡片。
  • 模式按钮（★ / 观看最多 / 点赞最多）是开关：再点一次即退出该模式。

随机推荐 Random pick

  • 三种模式：作品 / 作者 / 标签。作品可从全部可见画廊抽取，也可先在某座画廊内用筛选栏收窄范围。
  • 每次点 🎲 随机 抽一页（24 张作品/作者卡片，或恰好一个标签）。标签用一张大卡片揭示，点开进入标签结果页。
  • 作者按派生的 NSFW 状态过滤；标签只从当前可见画廊的词表里去重抽取，所以 SFW 模式下不会抽到只属于 NSFW 的标签。

10. 搜索 Search

  • 侧栏的搜索框聚焦或提交即打开搜索页（与画廊筛选状态相互独立）。
  • 三种范围：作品 Entries、标签 Tags、作者 Authors。
  • 支持近似拼写；作者搜索也会匹配其已记录的别名拼写（输入别名，结果卡片仍显示作者本名，下方以淡色显示命中的拼写）。
  • 标签搜索受当前 Show NSFW 偏好影响：SFW 模式会略去只被 NSFW 画廊使用的标签，共享标签的计数也只统计 SFW 用法。
  • 进入某个结果再返回，会带回原来的查询与范围，不会重置。

11. 设置 Settings

点顶栏齿轮打开设置面板（日常用得到的都在这里）：

  • 显示 NSFW 画廊与作者：全局可见性开关。关闭时隐藏 NSFW 画廊、NSFW 作者、合集里的 NSFW 成员/封面/计数，以及随机推荐里的 NSFW 内容。
  • 语言 Language：English / 简体中文。
  • 每页行数 Rows per page：控制画廊网格每页行数（手机端自动翻倍）。
  • 主题色 Accent color：蓝 / 青 / 紫 / 玫瑰 / 琥珀 / 绿，六套预设。
  • Connect to APP：手机配对区块（见第 14 节）。
  • 进阶功能 Advanced function：进入进阶功能页（第 12 节）。

顶栏还有一个明/暗主题切换按钮。

12. 进阶功能 Advanced

进阶功能页的标签很多，窄屏可左右滚动。各标签页：

标签 Tags（词典）

  • 自动列出资料库中已有的作品标签及其映射，按未映射 / 已映射分组。新作品带入的标签会直接出现，可以手动翻译成中文或统一名称。
  • 未映射表示尚未指定规范名，可填入映射，也可选择保留原名；作者名字的统一在「作者别名」中管理。
  • 删除标签需要再次确认，会从所有关联作品移除这个标签；映射记录的移除按钮只移除该映射，两种操作分别提供。
  • 标签合并：选保留的标签与被吸收的标签，确认后所有赋值改指向保留者，被合并的行直接删除（执行前自动备份）。

作者合并 Author merge

  • 一键检测重复作者：第一次点只是列出计划分组，再点一次才执行（带备份与完整性报告）。
  • 识别规则包括：规范化同名、分隔符变体（_/-/. 视为空白，arai_kazuki 与 Arai Kazuki 视为同一人）、以及经 producer 词典解析到同一规范名的拼写。
  • 每组保留作品最多的行；作品数相同时优先保留不含分隔符的拼写。作品、作者标签、作者评分、文件夹都会迁移到保留行。

作者别名 Author aliases

见第 7 节「作者」。

画廊模板 Gallery templates

  • 按画廊展示模板概要：结构维度、tag→维度归属、本地文件路径（<type>.template.json / <type>.tag-layout.json）与是否已生成。
  • 模板的保存与应用在任意作品卡片上进行（工具栏的「保存为模板」「应用 tag 布局」）。
  • 通用模板 Common template：仓库自带的板块/维度（基本信息 / 类型 / 角色 / 语言 / 标签 / 所有标签 / 综合评分），应用即复制进该画廊，之后可自由改名/清空/删除。它同样带有「内容种类」（每个画廊自带 Source URL / description；作品有内容时才显示该行）。
  • 标题缩减（模板卡片内的一个子卡片）：针对 原文 | 译文 形式的标题，逐条列出两侧，由你决定保留前半还是后半。默认会按可判断方向预选（译文侧含汉字/假名时保留译文；另一侧只有韩文时保留原文；两侧都是纯 ASCII 时不预选）。执行前自动备份，且只应用标题仍与清单一致的条目。

未分类 Tag Unassigned tags

  • 按画廊列出仍落在默认未命名位置的标签；选择目标维度即可归位（已归类的作品自动跳过）。
  • 若某标签在同类作品的其它地方多数放在某维度，会给出 Follow 一键跟随。

来源维护 Source maintenance

见第 12 节的来源库部分。

系统 System

  • 错误与日志：显示桌面服务的日志尾部、最近的客户端错误，可一键复制用于报错。
  • 手机配对诊断：包含当前 App 本机记录的扫码、连接、授权验证和保存阶段。配对失败弹窗也可直接复制诊断；即使尚未配对或电脑不可达，本机记录仍可读取。已安装的旧版 App 仅提供其自身版本支持的诊断。
  • 数据库：立即备份、导出（下载为真实的库文件）、从文件恢复。恢复是暂存式的：上传后先校验并暂存，需要你从托盘退出并重开桌面端才会真正替换（替换前会先把当前库另存为备份）。
  • 设置：启动时自动允许手机访问（默认开）。关闭后桌面端不会向局域网广告地址。

13. 从网站导入

导入分两条路，都在 T³ 界面内完成：规则构建器（学一个网站）和链接导入（把抓取结果落到库里）。

第一步：规则构建器（SiteProbe）

它会在你的浏览器里打开真实页面，让你点选，然后为这个站点学出规则。过程全程有引导，首次大约几分钟。

  1. 准备工作页地址：准备 2–3 个该站不同作品的网址（作品适配器）。想学全标签就选标签多的作品；允许多作者就选多作者的。
  2. 点「开始作品适配器」后，浏览器会打开标注页。把页面上真实的值复制、黏进搜索框，选最匹配的候选。工具会打分，但分数不是重点，选你认为最对的；像 $authorS$、123title456 这类「页面代码」可能得分很高，但如果页面上显示的是干净值，工具一定也抓到了它。
  3. 一个 / 多个：作者、标签、角色等可多值字段可以切换模式。「多个」下逐项点击加入，再点移除；也可选中整块标签，页面会展示拆分后的成员。规则如果还会读到所选之外的成员，保存提示会列出它们，这些成员也会进入导入结果。
  4. 长简介与后续纠正：长候选只在界面缩略显示，并注明全文字数，保存与导入保留全文；网站本身截断的值另有警告。后一次重新选择的字段优先，其他没有改选的字段沿用先前选择。
  5. 看到「适配器已生成」后可导入第一件作品预览，确认结果。
  6. 需要的话再建列表适配器（search / artist / favorites / album / playlist）：填列表的第一页地址与第二页地址（第二页是必填——它教适配器如何翻页），按引导标注卡片。
浏览器采集工具可使用系统 Edge / Chrome 或包内 Chromium / Firefox。遇到登录或安全验证时，按浏览器提示手动完成，再继续任务；站点特有的加密、专用接口或复杂限制仍可能需要单独的适配规则。
规则要能命名自己的地址列表适配器学到的规则必须能翻页、能定位每一张卡片的作品地址——只认识一个地址的规则是失败的设计。因此第二页地址是必填的。

第二步：链接导入

重新进入导入面板会恢复仍在运行的导入、登录或规则学习任务，并提供停止入口。规则学习等待标注时，可以同时用已安装的规则导入；另一个导出任务占用目录时，会显示对应任务和日志位置。改贴新网址会保留正在运行任务的控制入口。

  1. 新建页（或进阶功能里的导入面板）提供导入导出文件夹（拖入或浏览选择）与批量导入（拖入包含 items/<id> 子文件夹的父文件夹）。
  2. 选好画廊 / 类型。映射会根据该类型已保存的模板自动预填：分类标签→标签维度，作品→Series、登场人物→Characters、作品类型→Type、language→Language，作者→作者。未映射的字段保持「忽略」，绝不猜。
  3. 若该画廊还没有模板，会提示：用通用模板，或自建模板（否则标签会丢失）。
  4. 模板卡片预览会实时显示每个字段映射将产生的标签落点。若模板有 Type 维度，可手工补一个作品类型值（会作为 Tag 存入该维度）。
  5. 按作者评分：复核页不给单件作品打分，而是按作者名提供评分——勾选「给该作者评分」后展开该画廊的评分维度。评分存在作者身上，本批次的每件作品共用这一次决定。
  6. 点「导入 N 个条目」提交。导入是幂等的：已有的作品会被跳过并报告为「库中已有」，重复导入安全。
导入后的复核导入完成会进入一个一次性的批量复核合集，标记新卡片与「库中已有」的卡片。你可以随时完成或从侧栏离开。若一批太大一次看不完，点 存为临时合集，把整批放进名为「临时」「临时2」…的合集里，复核结束后它仍保留。

更新与游标

库会记住每个站点的工作 id 与每个列表的更新游标。因此一个月后再抓同一收藏夹，只需要抓新增的那些，旧的自动跳过。命令行入口：

pnpm import:cursor status --site hitomi.la --kind folder --ref folder-42
pnpm import:cursor filter --site hitomi.la --ids 100,120   # 只列出还没有的 id
pnpm import:cursor set    --site hitomi.la --kind artist --ref some-artist --source-id 3220586 --commit

来源库与来源维护

  • 来源库是从所有作品的 Content 里动态提取的网址集合：已知站点按 known:<site> 归类，其它按 host:<hostname>。手动新增的 Content 也会立即被识别，无需额外同步。
  • 来源维护用于站点失效/换域名时：先给来源组打上 invalid 标注（只标注，不动任何内容），再对候选做检索、按证据分档（exact-safe / strong-review / …）复核，最后一次性提交。提交会重新校验每一项并先做真实备份，任何过期事实都会整体中止（409，零写入）。旧网址永远不会被替换或删除，只会追加新的 Source URL。

14. 离线资料库

浏览器（含手机 App 的 WebView）可以保有一份离线副本，断网时照常浏览与做部分编辑，联网后自动同步。相关设置都在进阶功能 → 离线资料库。

首次下载

  1. 点 Download offline library。可选离线媒体级别：仅元数据（不含图片）、缩略图（不含原图）、或指定原图（填原始素材引用）。
  2. 下载会先落地元数据，再预载媒体；进度会显示「已处理/总数」。预载只在本页打开时进行，中断的下载会在下次启动时续传。

自动更新与自动同步

  • 重新连上服务器后，会自动把本地离线编辑重放（syncing），再自动更新已保存的副本（updating）——不再需要手动的 Sync now。
  • 空闲心跳不会重复下载；失败的更新会留待后续心跳重试。
  • 进度与错误横幅只提供信息，成功后自动消失。

离线能做什么

  • 浏览：画廊、作品、作者、筛选、合集、搜索、随机、稍后再看等读操作。
  • 编辑现有作品：标题 / 日期 / 页数等标量、评分值、标签的增/移/删、作者的新建与关联/解绑、内容（Content）的增删改排序、作品的封面与预览（新增/替换/删除/排序）。
  • 创建：带封面/预览的新作品。
  • 合集：创建、改名、NSFW、成员增删、排序。
  • 使用事件：浏览与点赞（每次是一个独立事件，丢响应也不会重复计数）。
离线不做的删除作品、合并作品、导入、模板/词表等破坏性或全局操作仍需桌面服务端；界面会明确提示「离线不可用」，而不是去连服务器然后弹报错。

系统信息与诊断

离线资料库页最下方是诊断区：离线编辑支持概览、存储用量与持久化状态（自动检查并自动请求持久化），以及可复制的完整报告（缓存的能力标志、快照头与 ACK、本地意图、媒体/队列错误、原生传输状态等）。报错时把这份报告复制给维护者即可。

待处理工作

待处理工作（排队中的编辑与暂存的图片）是透明的：重连后自动同步，界面上没有手动的导出/恢复入口。

清理只发生在落地之后队列里的操作一旦被证明已在服务器落地（有更新的快照覆盖了对应回执），本地才会移除它。取消一次排队操作绝不会顺手毁掉数据。

15. 手机端

配对（一次即可）

  1. 在桌面端打开 设置 → Connect to APP，点创建配对二维码。
  2. 二维码2 分钟内有效，请立刻用手机端扫描；也可用下方的复制粘贴方式（不是扫码）。
  3. 连接是加密的，并做了证书固定。授权失败或证书问题都不会清空你已排队的工作。

面板底部是已授权设备列表，可撤销设备或删除记录。还有一个手动恢复加密连接的折叠区，仅在崩溃留下死锁时使用，需按提示核实真实的 PID，绝不猜。

新版 App 的配对失败提示会区分二维码过期、连接或证书校验、授权及保存等阶段，并显示诊断编号。先复制本机诊断，再按具体提示处理；桌面日志可用同一编号关联。诊断不包含二维码、授权令牌或配对密钥。

使用

  • 手机端是同一套界面，响应式布局；窄屏侧栏变抽屉。
  • 所有触屏交互都有明确的点按路径（不依赖长按、悬停或 HTML5 拖拽）；触控目标约 44×44 CSS 像素。
  • 删除等破坏性操作使用桌面端同样的两段式确认（先点一次「预备」，再确认）。
  • 浏览器返回与页面内返回都会恢复原页与滚动位置；打开新页面总是从顶部开始。

离线与同步

手机端常驻离线副本：断网可浏览、编辑、创建、补图、合并（部分），联网后自动重放并更新副本。Android 会调度受限网络下的后台传输；依赖未就绪的编辑会等它的前置完成后才进行。超大图片（原生上限 20 MiB）需要前台 Update。

手机上「离线可编辑」之外的操作会直接标注为不可用，并提示 not available under offline，不会徒劳地去连服务器。

16. 备份与恢复

  • 命令行：pnpm db:backup 生成一份自包含备份目录（库快照 + assets/ + manifest）；pnpm db:restore <备份目录> 恢复。恢复前会校验备份能通过 db:doctor，并先把当前库另存一份。
  • 应用内：进阶功能 → 系统 → 备份 / 导出 / 恢复。恢复是暂存式的，需要从托盘退出并重开桌面端才生效。
  • 恢复前请先停止 T³ 服务（否则会因文件被占用而明确报错，而不是静默半覆盖）。
  • 只有完整的备份目录能通过工具恢复；旧的单文件快照（如 library.db.merge-backup-*）缺少素材树，不能用它恢复。

17. 排错与常见问题

界面显示「正在查看已保存的离线副本」

说明桌面服务暂时连不上，当前用的是离线副本。服务恢复后会自动切回在线并同步。若这是刚重启桌面端后的几秒，属正常现象。

改了服务端代码但界面没变

打包入口（T3.exe / T3.bat）只在启动时加载一次服务端源码，需要重启；只重建前端会留下「新前端 ↔ 旧服务端」。开发时用 pnpm dev:server（带 watch）。

手机端「输入后不弹候选」

已知的输入法（IME）组字问题已修：输入框用普通的 @input 读取（v-model 在组字期间会丢事件）。若仍异常，请确认已装最新版。

作品封面在网格里是旧的

媒体地址是按位置命名的，同一地址可能先后是不同字节。修改封面后回到网格若仍是旧的，重新打开该作品即可；详情页总是取原图。

导入报「服务端仍在处理」

导入没有在预期时间内完成，但服务端可能仍在写入。同一批次导入两次是安全的（幂等）——重试前先看一眼作品列表。

需要报告 bug

到进阶功能 → 系统或离线资料库底部，点「复制用于报错」，把整份报告贴给维护者。它包含日志尾部、客户端最近错误、能力标志与队列状态。

本手册随版本更新。若界面文字与本手册不一致，以界面为准；本手册对应 docs/status.md 所述的当前状态。
